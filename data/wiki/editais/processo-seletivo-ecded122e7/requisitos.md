# Requisitos e contratação

## Visão geral

Para participar de um concurso público, é necessário cumprir os requisitos básicos estabelecidos pelo edital e apresentar a documentação exigida.

## Informações principais
- nomeação dentro do limite de vagas dos cargos estabelecido em edital, obedecida a ordem de classificação
- cumprimento dos requisitos básicos para admissão no serviço público
- documentos que comprovem o cumprimento dos requisitos básicos
- demais documentos necessários para contratação
- entrega de documentos exigidos: Vagas Reservadas PcD (Pessoas com Deficiência)
- A documentação para comprovação das exigências mínimas para o cargo será solicitada no momento da Nomeação

## Como interpretar
Esta página apresenta apenas o que pôde ser organizado no tópico. Quando houver dúvida, confira a página de fontes e o documento original.

## Leitura editorial

Esses requisitos incluem escolaridade, formação, documentos e registro profissional. É importante verificar se você atende aos requisitos específicos do cargo que deseja concorrer.

## Pontos de atenção
- Verifique se você cumpre os requisitos básicos para admissão no serviço público.
- Certifique-se de que tem todos os documentos necessários para contratação.
- A documentação exigida pode variar dependendo do cargo e da instituição.
