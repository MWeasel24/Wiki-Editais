# Cronograma

## Visão geral

O cronograma abaixo consolida o cronograma original do edital e as alterações identificadas nas erratas/comunicados. Como o concurso foi suspenso em 02/05/2016 por determinação do TCE-AM, as datas posteriores à suspensão devem ser tratadas como datas previstas no edital, não como confirmação de realização.

## Eventos identificados

| Evento | Data/período |
|---|---|
| Divulgação do edital | 29/02/2016 |
| Inscrições pela internet | 09/03/2016 a 18/04/2016 (prorrogadas até 05/05/2016) |
| Pedido de isenção | 09/03/2016 a 19/03/2016 |
| Resultado dos pedidos de isenção | 14/04/2016 (data retificada pela Errata IV; cronograma original previa 04/04/2016) |
| Homologação provisória das inscrições | 02/05/2016 |
| Recursos contra inscrições não homologadas | 02/05/2016 a 16/05/2016 |
| Homologação definitiva das inscrições | 18/05/2016 |
| Locais e confirmação de data das provas objetivas | 20/05/2016 |
| Prova objetiva | 19/06/2016 |
| Gabarito preliminar | 21/06/2016 |
| Recursos | 21/06/2016 a 23/06/2016 |
| Gabarito definitivo | 27/06/2016 |
| Envio das provas de títulos | 21/06/2016 a 27/06/2016 |
| Resultado provisório das provas objetivas | 11/07/2016 |
| Resultado provisório das provas de títulos | 11/07/2016 |
| Recursos das provas de títulos | 13/07/2016 |
| Resultado final e homologação | 18/07/2016 |

## Interpretação

O edital-base previa prova objetiva em 19/06/2016 e resultado final em 18/07/2016. Porém, o comunicado de suspensão informou que novas datas e prazos seriam reapresentados após correção da legislação municipal.
