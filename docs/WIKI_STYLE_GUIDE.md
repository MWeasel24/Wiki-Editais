# Guia de estilo da LLM Wiki

A WikiEditais escreve páginas para candidatos, não para máquinas. Cada página deve explicar o edital com linguagem clara, tópicos úteis e fontes.

## Regra principal

Nunca transformar `source.md` em página final. `source.md` é evidência bruta. A página final deve ser interpretada.

## Tom de escrita

Use linguagem direta:

- “O edital informa...”
- “O candidato deve conferir...”
- “A informação não foi identificada com segurança...”
- “A retificação altera...”

Evite:

- “Trechos recuperados”
- “Material bruto”
- “Conforme texto extraído abaixo”
- copiar parágrafos longos do edital

## Estrutura mínima

Toda página deve ter:

1. Visão geral.
2. Informações principais.
3. Como interpretar.
4. Pontos de atenção.
5. Fontes usadas.

## Exemplo de página boa

```md
# Inscrições

## Visão geral
Esta página reúne as informações necessárias para o candidato realizar a inscrição no concurso.

## Período de inscrição
- Início: 09/03/2016
- Fim: 05/05/2016

## Taxa, pagamento e isenção
A taxa varia conforme a escolaridade exigida para o cargo. O pagamento deve seguir as regras do edital.

## Como interpretar
O prazo de inscrição é diferente de prazo de recurso, homologação de inscrição ou resultado.

## Pontos de atenção
Houve prorrogação das inscrições, então a data final consolidada deve considerar o comunicado mais recente.

## Fontes usadas
p. 2, p. 36, p. 38
```

## Exemplo ruim

```md
# Inscrições

Trechos recuperados:
[p. 36] 3.1.1 ...
[p. 37] 3.1.2 ...
```

Isso é dump, não wiki.
